## Part 10 — Spark SQL Comparison

A temporary SQL view named transactions was created from the generated transaction DataFrame 
using transactions.createOrReplaceTempView("transactions"). This allowed the DataFrame to be queried using Spark SQL.
The transaction summary was first calculated using the PySpark DataFrame API. The data was grouped by transaction type, and the 
transaction count, total transaction amount, and average transaction amount were calculated using groupBy() and agg().

The same analysis was then performed using Spark SQL with SELECT, COUNT(), SUM(), AVG(), and GROUP BY.
Both approaches produced identical results for CREDIT and DEBIT transactions in the generated dataset of 100,000 records.

The two versions perform the same business operation but use different syntax. The PySpark DataFrame API expresses the operation
 through Python methods, whereas Spark SQL expresses it through SQL queries. This demonstrates that the same analytical task 
 can be performed using either approach in Spark.
